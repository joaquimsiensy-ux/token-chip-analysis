# 题 7：三条链的供应量，分母该怎么定

## A 节·执行输入（可投喂，零泄漏）

**场景**：一个部署在三条链上的老牌 DeFi 币：Arbitrum（主链，totalSupply 10,985,596 枚）、Avalanche（totalSupply 635,046 枚）、Solana（totalSupply 98,410 枚）。另注意到 Arbitrum 上有一个"锁仓适配器"合约锁着 733,655 枚。主流行情站报总供应 10,449,597 枚。你要定全局分母来算所有实体的占比。

**数据指向**：案目录 `fable筹码分析/GMX分析/`（findings.md+analysis-state.json）。不在则三链 RPC 实查。

**任务**：给出全局总供应分母及其推导，并解释行情站数字为何对不上。

## B 节·考官侧（禁止进入执行会话上下文）

1. **当年确证错误**（GMX 2026-07-26，报告口径关键点）：**三链供应不可相加**——Arbitrum 锁仓适配器锁的 733,655.04 ≈ Avalanche 635,046.17 + Solana 98,409.61（差 0.03%＝在途），后两链是**镜像**（跨链背书关系：主链锁多少、镜像链发多少）。全局总供应＝Arbitrum totalSupply 10,985,596 枚，仅此一个。按三链相加会把所有占比**低估 5.8%**。行情站 10,449,597 枚是 2024-09-02 的历史快照（第三方供给必须注明抓取时点）。
2. **唯一失败原因**：多链分母直接相加，没做"锁仓适配器 ≈ 镜像链供给之和"的配平检验（不检验就发现不了镜像关系）。
3. **禁止输出**：全局总供应=三链 totalSupply 之和（≈11,719,052）；用行情站快照当当期链上分母。
4. **必做证据动作**：①多链标的先跑链分布盘点（各链 RPC 实查供给）；②查主链上有无桥/锁仓适配器，做"锁仓量 vs 各镜像链供给"配平（差值应在在途误差内）；③配平成立→分母取主链 totalSupply，镜像链不另计；不成立→按 mint−burn 口径逐链核。
5. **缺证据时的结论上限**：镜像关系无法确证时，报告必须**双口径并列**（主链单独 / 全链合计）并声明差异影响面，**不允许**静默选其一。

**预期拦截点**：casebook/supply-accounting.md 镜像恒等式条 + analyze-workflow 阶段 0 多链硬关卡（链分布盘点+配平步骤）+ playbook-supply-recon §1b 多链分母判据。
