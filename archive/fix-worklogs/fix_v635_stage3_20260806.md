## AUTO_GATES 评估

- 已机器化：`accounting_mode.json`、`supply_truth.json`、`time_spotcheck.json` 已有统一 `verdict/exit_code`；本批新增 `reconciliation_report.json`（runner 自身 `verdict/exit_code`），均由 AUTO_GATES 重读，禁止 declared 覆盖。

## R7-14 非作者对抗审（六视角①②首例）

- ①字段来源审计：`risk_flags` 的比较值不读取上游“已规范化”布尔或缓存结论，而是对当前发布行和 staging 行的原始字符串分别执行 `split('|') → strip → 去空 → set 去重 → sorted`。因此排序、空段、重复段和段内空白都由本地重算消除；真实集合差异仍进入 `changed`。

裁决：①②未发现新的字段自报或 fail-open；R7-14 可摘牌。
