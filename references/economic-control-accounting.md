# 经济控制账本：控盘比例的主口径

## 1. 先回答真正的问题

筹码分析问“庄控制多少”，问的是**最终经济控制量**，不是钱包列表里还剩多少币。币进入 LP、CEX、桥、质押、锁仓、vault 或托管合约，只改变保管位置；只要实体仍拥有可证明的赎回权、提现权或受益权，就没有因此失去经济控制。

必须同时维护三套互不替代的账：

| 账本 | 回答什么 | 公共设施怎么处理 |
|---|---|---|
| 实体成员表 | 哪些 EOA/专属合约可归为同一控制主体 | 公共池、路由、CEX 热钱包、桥、协议金库不进成员表 |
| 链上位置账 | 截止时币实际停在哪类地址 | 按钱包、池、CEX、桥、锁仓等位置展示 |
| 经济控制账 | 截止时谁拥有可证的最终受益权或赎回权 | 只把可归属份额穿透回受益实体，未归属部分留在设施/未决桶 |

**成员表排除公共设施，只是在防止错误聚类，不是在放弃设施内权益。** 把“设施不是实体成员”外推成“设施里的币不算实体控制”，会系统性低估庄家控盘，是结论级错误。

## 2. 纳入门槛：有权取回，且数量可复算

一项设施权益只有同时满足下面两条，才进入“可证经济控制量”：

1. **权利可归属**：能证明头寸/份额/子账户/受益人由该实体控制，或存在只有该实体能完成的闭合存取链。
2. **数量可复算**：能在目标时点算出该权利可兑换的标的代币数量，而不是只看到历史存入额或设施总余额。

常见设施按以下规则处理：

- **钱包自持**：实体成员地址的可用余额直接计入。
- **V2 LP**：按实体持有的 LP token 份额乘目标时点池储备，计算其可赎回的标的代币；LP token 已质押时继续穿透质押凭证。不得把整池余额归给单一 LP。
- **V3/V4 集中流动性**：先用 NFT/position key 的所有权历史确权，再按目标时点的流动性、tick 区间与现价计算可赎回本金；标的币计价的已应计可领取手续费可另列并计入经济权益。V4 单例 PoolManager 必须绑定到具体 `poolId + position`，不得拿单例合约总余额代替池或仓位余额。
- **vault/质押/锁仓/托管**：按 share、beneficiary、position 或内部账本穿透到受益人；协议残差在扣除全部已归属权益后才算协议自身余额。
- **CEX**：只有在子账户/API 余额、交易所出具的账户证明、唯一 memo/充值账户映射、可验证提现挑战，或闭合的“存入—所内账户—由同一主体提现”证据足以证明持续受益权时才计入。仅看到某钱包向 CEX 热钱包充值，只能证明“进入交易所”，不能证明之后仍属于该实体。
- **跨链桥**：按受益人的锁定/铸造/赎回权计一次。源链锁仓与目标链映射币是同一经济权益的两面，禁止两边同时计入。
- **借贷/抵押**：区分所有权和处置权。抵押资产仍属实体但受清算约束；借入代币不能仅因在钱包里就当成净控盘。报告同时给毛控制量与扣负债后的净经济敞口，庄级判定（大庄/小庄门槛，tiering §6a）默认按可实际处置或赎回的毛标的币数量过线，并注明抵押限制。

不满足门槛的放入 `unresolved_facility_exposure`，说明缺哪条证据；不得为了凑“完整控盘”把设施总余额、历史存入额或同一交易路径全部归庄。

## 3. 证据分层与主结论

经济控制结论固定分三层：

1. **可证经济控制下限**：严格成员钱包余额 + 权利与数量都可闭合的设施权益。这是 TL;DR 回答“控制多少”的主数字，也是庄级门槛机械判定的份额口径。
2. **强关联扩展范围**：地址或设施受益权高度疑似但未达到确权门槛的增量。与下限并列给范围，不得冒充单一主体实锤。
3. **未决设施暴露**：确定有币在设施里，但无法证明最终属于谁。单列规模与不确定性，不并入前两层。

“钱包直接持有 X%”只能放在位置拆分表中。只要可证设施权益显著，禁止把直接钱包比例放在 TL;DR 当作庄家控盘答案，也禁止用“严格实体地址”与“经济控制下限”互相替代：前者是成员证据边界，后者还必须加上该成员拥有的可证设施权利。

## 4. 时间序列与离场判定

每个事件时点都按下面的守恒式重建：

`实体经济控制 = 钱包自持 + 可赎回 LP 标的币 + 可证 CEX 账户权益 + 可证桥/质押/锁仓/vault/托管权益 − 同一权益的重复映射`

- 钱包向自有 LP/锁仓/vault 转币是**位置重分类**，不是清仓。
- LP 内标的币数量会随价格、tick 与成交变化，历史曲线必须按时点重算可赎回量，不能一直沿用初始存入额。
- 头寸 NFT、LP token、vault share 或账户受益权转给无关联方时，经济控制才在该时点退出。
- 充入 CEX 后若只能证明充值、不能继续证明所内受益权，链上可证经济控制在此进入“未决”；不得武断写继续持有，也不得武断写已经卖出。
- 赎回只是在设施权益和钱包余额之间换形态；两边同一时点不能重复计算。

## 5. 必需产物 `economic_control_ledger.json`

每个大庄/小庄候选在冻结标签前生成该文件。最低结构：

```json
{
  "cutoff_block": 0,
  "supply_denominators": {},
  "entities": [{
    "entity_id": "stable-id",
    "wallet_self_held_raw": "0",
    "confirmed_facility_claims": [{
      "facility_type": "v3_lp",
      "facility_id": "pool-or-account-id",
      "position_id": "position-id",
      "ownership_evidence": [],
      "amount_method": "target-block redeemable amount",
      "token_raw": "0",
      "as_of_block": 0,
      "double_count_key": "unique-economic-right"
    }],
    "confirmed_economic_control_raw": "0",
    "expanded_economic_control_range_raw": ["0", "0"],
    "unresolved_facility_exposure": []
  }]
}
```

发布前逐实体检查：

- `confirmed_economic_control_raw = wallet_self_held_raw + Σ confirmed_facility_claims.token_raw`；
- 所有 `double_count_key` 全局唯一，桥双边、LP 本金与钱包赎回结果没有重复；
- 每项设施权利都有目标时点所有权证据和数量算法；
- 图 2、实体表、TL;DR 控盘比例、庄级判定来自同一账本；
- 图 1按位置展示，图注解释与图 2差异；
- 强关联扩展和未决设施没有混进可证下限。

文件缺失、存在未裁决的大额设施权益、或加总不闭合时，不允许发布“庄控制多少”的结论。
