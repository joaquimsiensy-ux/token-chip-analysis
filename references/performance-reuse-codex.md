# Codex 分支的装载与验证复用

本机制仅改变装载、复用和调度，不改变归属算法、阶段边界或复核责任。
对正在运行的案例，先保存进程、脚本与输入指纹；修改在独立副本验证，已有任务自然完成。
升级后重新运行正式消费者建立当前绑定，不能编辑旧 PASS 或用缓存替代冻结收据。

## 三种依赖

| 结果 | 必须重新核对的依赖 | 失效条件 |
|---|---|---|
| Solana 原始行物化 | 当前正式 resolver、原始字节、元数据、列契约、装载代码与运行库、物化文件完整 SHA | 任一来源或装载依赖变化；数据库/认证记录损坏 |
| 来源计算 | 原始身份与内容、名册、标签、计算范围、供应分母、算法与参数 | 其中任一变化；结果缓存损坏 |
| 深验 | 实际读取的完整证据叶子、路径解析和存在性观察、算法、参数、运行时 | 任一内容或观察变化；读集合不完整；凭证损坏 |

代码指纹按代码对象及常量的稳定内容编码，源路径先规范化；不能使用受对象引用状态影响的
`marshal` 字节充当跨进程算法身份。磁盘完整 SHA 与实际驻留函数分别核验。
进程内代码、默认参数或已载入的算法依赖不能与当前源码对应时，拒绝复用并要求重启；
新文件 SHA 不能替旧函数的计算背书。

确认文件、报告披露文字、manifest 的登记时间和 run ID 不参与来源模拟。
来源计算仅投影排除确认及非计算登记字段；manifest.scope 仍是计算输入。
每次仍验证当前确认与当前名册、翻转指纹及台账的绑定，并组装新的确认层。
撤回、缺失或不匹配的确认不能因计算缓存命中而放行。

## 正式消费与独立复核

`wave_scan.load_sol` 为正式 Solana 调用保留九列，金额使用 HUGEINT，无浮点中转；
slot、交易序号、指令序号、顺序精度与 ingest_seq 全部保留。warm 读取只读数据库。
收到已有 preflight 时先重新校验正式选择，装载结束后再校验，不能用旧字典绕过 CURRENT。
旧五字段探索格式维持原契约。

来源计算与 P4 独立重放使用不同缓存空间。P4 首次必须启动
`entity_source_trace.py --compute-cache-mode off` 并与候选完整计算内容比较。
只有该次真实独立重放可以签发 P4 自己的结果凭证；以后同依赖、同候选才可复用。
候选台账的 PASS、publishable 或计算缓存不能签发独立重放凭证。

深验复用与 `DeepReconciliationWitness` 的一级 frontier 相互独立。
新凭证只在真实成功深验后产生，记录完整实际读集合，命中时完整重哈希所有叶子。
部分读取、无法证明完整的读集合或校验期间变化，均不签发可复用凭证。
独立深验可共享已核验原始行物化，但仍执行自己的对账和修复检查。

文件路径、必填参数、名册结构、裁决收据、台账结构先于昂贵重放检查。
归属与确认尚未闭合时不启动最终重放；诊断性计算与正式冻结仍按各自退出语义区分。
freeze 与 P4 共用前置检查；所有必填路径齐全后先核对小算法文件的完整 SHA，
旧算法绑定无需启动链上深验即可拒收。前置通过不是可长期沿用的裁决；
长计算前后及冻结写入前，重新绑定实际使用的裁决、源报告和名册。
完整 distribution 独立扫描在裁决齐全后执行，扫描期间的名册或收据变化必须拒收。

## 缓存与运行记录

默认缓存位于案例的 `.runtime-cache/codex-performance-v1`。
`CHIP_PERF_CACHE_ROOT` 可将缓存放到独立验证目录；`CHIP_PERF_METRICS` 指定 JSONL 计数日志。
缓存目录和本机认证密钥属于运行资产，不纳入报告、handoff 或发布证据。
签名认证检测缓存连同摘要被改写；它不证明本机完全控制者无法伪造，亦不替代原始数据证据。
缺失密钥不能为已有凭证补签。不得对缓存手工补 PASS。

显式重跑开关：

- `--compute-cache-mode off`：来源计算重新执行，原始装载可复用。
- `CHIP_FORCE_INDEPENDENT_TRACE=1`：重新执行 P4 自己的计算。
- `CHIP_FORCE_DEEP_VALIDATION=1`：对账和修复算法重新深验，原始装载可复用。
- `CHIP_DEEP_RAW_CACHE=0`：深验明确从原始 JSON 解析，用于装载器独立验收。

严格只读审查不得在被审目录创建运行缓存；运行前指定获准的独立缓存目录，或只做静态审查。
每次全量计算须在 metrics 中记录原因。区分原始 JSON 解析次数、物化读取次数、
完整深验次数、独立 P4 次数和全叶子哈希成本。
验收至少测首次、重复、仅确认变化、计算输入变化及损坏情形；模块耗时不得冒充完整 −2 墙钟耗时。
